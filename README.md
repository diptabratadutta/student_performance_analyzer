\# Student Performance Data Analyzer



A Python-based Student Performance Analysis and Visualization project that helps analyze student marks, calculate academic performance, and generate meaningful insights through an interactive dashboard.



\## Project Overview



The Student Performance Data Analyzer is designed to simplify student result analysis. It processes student records, calculates total marks, percentages, grades, and ranks, and presents academic insights using charts and visualizations.



\## Features



\- 📚 Student Data Management – Load and clean student records.

\- 🧮 Total Marks Calculation – Calculate marks across all subjects.

\- 📈 Percentage Calculation – Calculate individual student percentages.

\- 🎓 Grade Calculation – Assign grades based on performance.

\- 🏆 Student Ranking – Identify top-performing students.

\- 📊 Subject-wise Analysis – Calculate average marks for each subject.

\- 📉 Grade Distribution – Visualize student grade distribution.

\- 🔍 Student Search – Search and filter student records.

\- 📥 CSV Download – Download filtered student records.

\- 👤 Individual Performance – View individual student performance.

\## Installation \& Setup



1\. Clone the repository

2\. Open the project folder



cd student-performance-analyzer

3\. Install required libraries



pip install streamlit pandas matplotlib

4\. Run the application



streamlit run app.py
